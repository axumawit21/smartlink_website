# SmartLink hero (phase 1)
Vite + React + TypeScript + Tailwind + three + gsap/@gsap/react.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # type-check + production build
    npm run preview

Contact details live in `src/config/site.ts`. Intro plays once per session (sessionStorage key `sl`);
clear it or open a private window to replay.
